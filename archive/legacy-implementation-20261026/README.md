# Retired implementation — October 26, 2026

This is a reversible source archive, not part of the active monthly application.

It preserves the earlier disease-specific and weekly implementations: dengue,
measles/rubella, leptospirosis, SARIMA/NNAR, old residual searches, callbacks,
charts, upload parsers, configuration, browser assets, validation scripts and
their tests. Some files depended on their original repository locations and
must be restored together before historical reproduction.

Do not run or install this directory as the current application. It is excluded
from normal pytest discovery, Python package discovery and Docker builds.
The supported application lives in `dashboard/monthly`; its acceptance tests
live in the root `tests` directory. Original source datasets and historical
evidence remain in their existing locations.

Bulk deletion was declined by automatic approval review; archiving keeps the
cleanup reversible without permanently discarding the old implementation.
